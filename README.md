# Blansyn Instagram Followers Following Tracker

![Blansyn Branding](https://www.blansyn.com/favicon.ico) <!-- Placeholder for branding if available -->

A professional, high-performance web application designed to track and manage your Instagram follower relationships with **100% privacy**. 

Developed by [Blansyn](https://www.blansyn.com), this tool processes all your data locally in your browser—your files never leave your device.

## 🚀 Features

- **Ghost Follower Detection**: Identify people you follow who don't follow you back.
- **Mutual Follows**: See the dedicated list of users you are connected with.
- **Fans Detection**: Find users who follow you but you don't follow back.
- **Zero Gravity UI**: A stunning, high-performance interface with glassmorphism and 3D animations.
- **Search & Filter**: Effortlessly find specific usernames in your lists.
- **100% Private**: No servers, no APIs, no tracking. Your data stays on your computer.

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Dilrukshan7/instagramAnalysis.git
   cd blansyn-instagram-tracker
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Access the tool**:
   Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📖 How to Use

To use this tool, you need to export your data from Instagram:

1.  Log in to Instagram and go to **Settings** > **Account Center** > **Your Information & Permissions** > **Export Your Information**.
2.  Choose **Select types of information** and check **Followers and Following**.
3.  Select **Download to device**, set the format to **JSON**, and click **Create files**.
4.  Once the download is ready, extract the ZIP file.
5.  Open the **Blansyn Tracker** and upload `followers_1.json` and `following.json` from the extracted folder.
6.  Analyze your results immediately!
